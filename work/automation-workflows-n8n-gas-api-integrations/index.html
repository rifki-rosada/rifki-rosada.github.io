Automation Workflows - n8n, GAS, and API Integrations

Built operations automations for order logging and WhatsApp tracking pipelines using n8n and Google Apps Script.

Automation Case Study

Problem

Operational logging tasks were manual, repetitive, and prone to inconsistencies between communication channels and spreadsheets.

Constraints

  • Workflows needed to be understandable by non-technical operations users.
  • Integrations had to stay resilient when third-party payloads changed.
  • Error handling needed to preserve auditability for operational reviews.

Approach

  • Implemented web order to sheet workflows with validation and normalization steps.
  • Added WhatsApp to sheet logging and tagging automations for tracking continuity.
  • Used n8n and Google Apps Script to balance flexibility, speed, and maintainability.

Result

  • Reduced manual copy-paste effort in daily operations.
  • Improved consistency of log records across channels.
  • Provided reusable automation patterns for future workflow extensions.

Tech Stack

  • n8n
  • Google Apps Script
  • REST APIs
  • Google Sheets
