Custom CRM - Sales Pipeline and Performance System

Designed and implemented a custom CRM platform to centralize sales pipeline visibility and performance tracking.

Web Platform Case Study

Problem

Sales activity and performance tracking were split across disconnected documents, making weekly reviews and decision-making slow.

Constraints

  • Needed to fit an existing operational process without stopping active sales work.
  • Required role-based access and stable reporting behavior for managers and contributors.
  • Had to run on controlled infrastructure with clear deployment ownership.

Approach

  • Mapped pipeline stages and reporting requirements before implementation.
  • Built the backend workflow and data model in Laravel with PostgreSQL.
  • Implemented the operator-facing interface in Next.js and containerized deployment with Nginx and Docker.

Result

  • Created one source of truth for pipeline and performance review.
  • Reduced coordination overhead between sales and leadership during weekly check-ins.
  • Delivered a system that can be extended with additional sales operations modules.

Tech Stack

  • Laravel
  • Next.js
  • PostgreSQL
  • Nginx
  • Docker
